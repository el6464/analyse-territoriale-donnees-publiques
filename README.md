# Analyse territoriale et suivi des indicateurs

## Présentation

Projet d'analyse de données réalisé dans le cadre d'une expérience professionnelle en collectivité territoriale.

L'objectif est d'exploiter des données issues d'enquêtes et de données territoriales afin de produire des indicateurs permettant de suivre l'évolution de la population et des ménages.

## Données

Les données utilisées dans le cadre professionnel proviennent notamment d'enquêtes et sont confidentielles.

Elles ne sont pas publiées dans ce dépôt.

Le dépôt présente uniquement les scripts et la démarche d'analyse, sans données individuelles ni données confidentielles.

## Méthodologie

La démarche comprend plusieurs étapes :

1. Exploration des données
2. Contrôle de la qualité des données
3. Nettoyage et préparation
4. Extraction et agrégation avec SQL
5. Analyse des indicateurs
6. Création de visualisations
7. Interprétation des résultats

## Analyses réalisées

- Analyse de la population
- Suivi de l'évolution démographique
- Analyse des ménages
- Calcul d'indicateurs territoriaux
- Agrégation des données
- Comparaison des périodes
- Analyse des évolutions
- Visualisation des résultats

## Technologies

- Python
- SQL
- Pandas
- Matplotlib
- Power BI
- Git / GitHub

## Confidentialité

Les données originales utilisées dans le cadre professionnel ne sont pas publiées dans ce dépôt.

Les scripts présentés sont destinés à documenter la démarche technique d'analyse.
